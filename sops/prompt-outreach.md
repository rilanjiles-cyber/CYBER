```

Tone: surgical, no filler, BTA brand voice. Operator talking to operator.
```

## CORRECTION PROMPTS

Use these when the output isn't right. Paste directly into Claude after the draft.

**Sounds like agency marketing:**
```
This reads like a marketing agency wrote it. Rewrite in BTA brand voice: surgical, no filler, operator talking to operator. Remove all agency speak — "leverage," "solution," "comprehensive," "we'd love to." Start over from the first sentence.
```

**Too long:**
```
Cut this by 50%. Keep only the sentences that do real work. Every sentence should earn its place. Remove everything that's just politeness or padding.
```

**Doesn't name the gap specifically:**
```
The gap isn't specific enough. Use the actual data I provided: [paste the key data points]. Name what you found, exactly. Vague is not BTA.
```

**Pitching in Touch 1:**
```
Touch 1 doesn't pitch. Remove any mention of services, packages, pricing, or what BTA does. Touch 1 only opens the loop — names what you noticed and asks one question. Rewrite.
```

**Tone is too aggressive:**
```
The tone is too pushy. This should feel like a peer who noticed something — not a salesperson who wants to close. Dial it back. Curious and direct, not pressure.
```
