# RILAN PERSONAL VAULT — SETUP
**Separate from BTA Ops. This is your growth OS.**

---

## STEP 1 — Open This Vault in Obsidian

1. Open Obsidian
2. Click **"Open folder as vault"**
3. Select the `Rilan-Personal` folder
4. Click **"Trust author and enable plugins"**

> ⚠️ Open this as a **separate vault** from `Rilan-BTA-Ops`. They stay separate.
> You'll switch between them via Obsidian's vault switcher (bottom-left icon).

---

## STEP 2 — Install Plugins

Go to: **Settings → Community plugins → Browse**

| Plugin | Author | Purpose |
|---|---|---|
| **Dataview** | blacksmithgu | Powers dashboard queries on Home.md |
| **Templater** | SilentVoid | Powers all note templates |
| **Tasks** | Martin Schenck | Track habit checkboxes with due dates |
| **QuickAdd** | Christian B. B. Houmann | One-keystroke note creation |
| **Calendar** | Liam Cain | Visual calendar view of daily notes |

After enabling Templater: Settings → Templater → **Template folder location** → type `Habits`

After enabling QuickAdd: Settings → QuickAdd → all 5 macros (Journal, Fitness, Skill, Direction, Reflection) should already be there.

---

## STEP 3 — Set Up Daily Notes

Settings → Core plugins → Daily notes → ON

Settings → Daily notes:
- **Date format:** `YYYY-MM-DD`
- **New file location:** `Habits`
- **Template file location:** `Habits/_Habit-Template`

Now **Cmd+Shift+I** = today's habit log, pre-filled with your daily standard.

---

## STEP 4 — Pin Home.md

1. Click `Home.md` in file explorer
2. Right-click the tab → **Pin**
3. This is your personal command center — open it every session

---

## STEP 5 — Set Hotkeys

Settings → Hotkeys — search and assign:

| Hotkey | Action |
|---|---|
| `Cmd+Shift+J` | QuickAdd: New Journal Entry |
| `Cmd+Shift+F` | QuickAdd: New Fitness Log |
| `Cmd+Shift+K` | QuickAdd: New Skill Note |
| `Cmd+Shift+D` | QuickAdd: New Direction Note |
| `Cmd+Shift+R` | QuickAdd: New Reflection |
| `Cmd+Shift+I` | Open today's daily note (Habit log) |

├── Skillset/

│

│   ├── _Direction-Template.md

## WHAT EACH SECTION IS FOR

| Section | Use It For |
|---|---|
| **Journal** | Stream of consciousness — what's on your mind, what happened, what you noticed |
| **Fitness** | Workout logs, nutrition notes, progress tracking |
| **Skillset** | Sales techniques, content skills, tech skills, anything you're actively learning |
| **Direction** | Goals, targets, commitments — with progress logs |
| **Reflection** | Weekly, monthly, quarterly reviews — honest accounting |
| **Habits** | Daily habit tracking — BTA output + personal standard + energy audit |
